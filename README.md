# JobFit Agent

An AI-powered job application assistant. Paste a job description and get a fit score, skill gap analysis, tailored cover letter, and resume bullets — generated by a six-agent pipeline streamed live to the browser. Includes a background job discovery feed (HackerNews, Reed.co.uk, Adzuna) and a cold email workflow for reaching out to company contacts.

---

## Features

- **Fit analysis** — six-agent pipeline scores your profile against a JD, identifies gaps, suggests learning resources, writes a cover letter and resume bullets
- **Job discovery** — scrapes HackerNews "Who is Hiring", Reed.co.uk, and Adzuna; two-stage relevance filter (keyword → Haiku LLM); saves scored jobs to a feed
- **Cold email** — discovers company contacts via Hunter.io and drafts personalised outreach
- **Cost dashboard** — tracks LLM spend per agent, per run, with prompt cache hit rates
- **Prompt caching** — Anthropic cache-control on system prompts; cache-aware cost accounting

## Quick Start

### 1. Clone and configure

```bash
git clone https://github.com/divyanshu144/Job_Agent.git
cd Job_Agent
cp .env.example .env
```

Open `.env` and set at minimum:

```
ANTHROPIC_API_KEY=sk-ant-...
```

Optional keys for job discovery and cold email:

```
REED_API_KEY=          # reed.co.uk developer key
ADZUNA_APP_ID=         # adzuna.co.uk app ID
ADZUNA_APP_KEY=        # adzuna.co.uk app key
HUNTER_API_KEY=        # hunter.io API key
```

### 2. Install dependencies

```bash
# Backend
pip install -r requirements.txt

# Frontend
cd frontend && npm install
```

### 3. Run

```bash
make run
# Backend: http://localhost:8000
# Frontend: http://localhost:5173
```

Or with Docker:

```bash
make docker-up
```

## Usage

1. **Register** at `/register` (first user gets admin role)
2. **Set up your profile** at `/profile` — upload your CV (PDF) and edit the YAML with your target roles, skills, and allowed locations
3. **Analyse a job** — paste a JD on the home page; watch the six agents run in real time
4. **Discover jobs** — trigger a discovery run from `/discover`; set `?source=reed` or `?source=adzuna` to use those boards
5. **Cold email** — from a results page, discover contacts for the company and draft outreach

## Architecture

```
backend/
├── agents/          # six pipeline agents + cold email agent (BaseAgent → Claude)
├── services/
│   ├── orchestrator.py      # two-phase SSE pipeline runner
│   ├── discovery.py         # background job scoring pipeline
│   ├── hn_client.py         # HackerNews scraper
│   ├── reed_client.py       # Reed.co.uk API client
│   ├── adzuna_client.py     # Adzuna API client
│   └── contact_discovery.py # Hunter.io contact finder
├── routes/          # FastAPI routers (auth, profile, analyse, discovery, contacts, metrics)
├── models.py        # SQLAlchemy ORM (Profile, Analysis, Job, LLMCall, …)
└── schemas.py       # Pydantic v2 request/response schemas

frontend/src/
├── pages/           # ProfileSetup, AnalyseJob, Results, Discover, Saved, Costs
└── components/      # AgentProgress, ScoreCard, GapList, DocViewer, …
```

The six pipeline agents run in two phases:

**Phase 1** (sequential): `job_parser → match_scorer → gap_analyst`

**Phase 2** (concurrent): `resource_planner + cover_letter + resume_tailorer`

Results stream to the browser over SSE as each agent completes.
